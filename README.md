# Tebak Aksara Jepang

Aplikasi kuis bahasa Jepang sederhana berbahasa Indonesia dengan tahap Hiragana, Katakana, Kotoba, dan Kanji.

## Menjalankan

Buka `index.html` melalui server lokal seperti Live Server. File `kotoba-jlpt-n5-n4.js` harus berada di folder yang sama dengan `index.html`.

## Sumber kosakata

Bank Kotoba mencakup kosakata komunitas JLPT N5/N4 dari [OpenJLPT](https://github.com/evanclan/OpenJLPT). Arti dataset diterjemahkan ke bahasa Indonesia. Atribusi dan lisensi tersedia di `KOTOBA-DATA-SOURCE.txt`.
